# Security Policy 🛡️

## Reporting Security Vulnerabilities

We take the security of TheClosedTest and our developer community seriously. If you discover a potential security vulnerability, please report it responsibly so we can resolve it before public disclosure.

### How to Report

- Please report security vulnerabilities privately through **[GitHub Security Advisories](https://github.com)** by clicking on the **Security** tab of this repository and selecting **"Report a vulnerability"**.
- **Details to Include**:
  - Description of the vulnerability.
  - Steps to reproduce or proof-of-concept.
  - Potential impact.

Please do **NOT** open public GitHub issues for security vulnerabilities.

### Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for triage and remediation.
- Once a fix is verified and deployed, credit will be given in the release notes (if desired).
